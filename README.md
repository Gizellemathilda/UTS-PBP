Proyek ini merupakan website portofolio pribadi saya Gizelle, mahasiswa **Teknik Informatika Universitas Negeri Surabaya (UNESA)**.  Website ini dibuat sebagai **proyek UTS** untuk menampilkan profil pribadi, pengalaman, pendidikan, dan keahlian menerapkan hasil pembelajaran HTML, CSS dan JS.

## Fitur Utama
- **Navigasi:** Menampilkan logo “Gizelle.” di bagian kiri dan daftar menu di bagian kanan. Menu terdiri dari Beranda, Tentang, Pendidikan, Pengalaman, dan kontak yang dapat diklik untuk berpindah ke setiap bagian halaman.
- **Beranda:** Menampilkan perkenalan singkat tentang diri saya dengan tampilan carousel foto agar terlihat lebih interaktif dan menarik ketika pertama kali membuka website. 
- **Tentang:** Berisi deskripsi singkat mengenai diri saya, serta daftar skill yang sedang saya pelajari selama kuliah.
- **Pendidikan:** Menampilkan riwayat pendidikan dalam bentuk timeline dari jenjang SMA hingga kuliah di Universitas Negeri Surabaya.
- **Pengalaman:** Menampilkan pengalaman saya dalam organisasi dan kegiatan lomba, termasuk prestasi yang pernah diraih saat sedang kuliah.
- **Kontak:** Menampilkan form kontak sederhana yang bisa digunakan untuk mengirim pesan atau pertanyaan secara langsung, serta dilengkapi dengan alert interaktif sebagai tanda bahwa telah berhasil mengirimkan pesan.
- **Footer:** Bagian penutup website yang berisi informasi kontak dan tautan ke akun media sosial saya seperti GitHub, Instagram dan email pribadi saya.
